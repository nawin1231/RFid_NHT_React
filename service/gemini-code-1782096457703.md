```mermaid
sequenceDiagram
    autonumber
    
    box LightCyan 1. พื้นที่หน้างาน
        participant OP as Operator
    end
    box LightYellow 2. Frontend
        participant UI as React (:3000)
    end
    box LightGreen 3. Hardware & Gateway
        participant PY as Python Reader (:8000+)
    end
    box LightPink 4. Backend
        participant API as Node.js (:5000)
    end
    box LightGray 5. Database
        participant DB as SQL Server
    end

    %% ========================================
    rect rgb(240, 248, 255)
    Note over OP,DB: ขั้นตอนที่ 1: Register
    OP->>UI: Scan Barcode ชิ้นงาน
    UI->>API: ขอข้อมูล Lot (Job Ticket API)
    API-->>UI: part_no, quantity, tray_counter
    OP->>UI: กดปุ่ม Confirm
    UI->>API: สั่งบันทึก Lot
    API->>DB: INSERT ลง tb_rfid_lot
    
    loop จนกว่าจะครบ tray_counter
        OP->>PY: นำ RFID Tag สแกนที่เครื่อง Register
        PY->>UI: ส่ง Tag ID (ผ่าน API /new-tag)
        UI->>API: สั่งบันทึก Tray (tag_id ผูกกับ barcode)
        API->>DB: INSERT ลง tb_rfid_tray
    end
    end

    %% ========================================
    rect rgb(240, 255, 240)
    Note over OP,DB: ขั้นตอนที่ 2: Pallet (before_washing)
    OP->>PY: นำ Tray ไปวางบน Pallet (W1-W7)
    PY->>PY: อ่าน Tag อัตโนมัติ
    PY->>API: POST location (เช่น W1) ไปที่ Node.js
    API->>DB: SP อัปเดตสถานะเป็น before_washing
    API->>DB: บันทึกลอเคชันลง tb_rfid_lot
    DB-->>API: เช็คยอด Tray
    alt Tray ยังไม่ครบ (tray_done < tray_counter)
        API-->>PY: return TRAY_NOT_COMPLETE
        PY->>PY: พิมพ์แจ้งเตือน Warning
    end
    end

    %% ========================================
    rect rgb(255, 245, 238)
    Note over OP,DB: ขั้นตอนที่ 3: Washing (after_washing)
    OP->>PY: Tray ออกจากเครื่อง Washing ผ่าน Reader ขาออก
    PY->>API: POST tag แจ้งเตือนเข้า Node.js
    API->>DB: SP อัปเดตสถานะเป็น after_washing
    PY->>UI: ส่ง Tag ให้หน้า Machine Validate (/new-tag)
    UI->>OP: แสดงรายชื่อ MBR ที่ตรงกับ part_no เพื่อให้พนักงานนำไปวาง
    end

    %% ========================================
    rect rgb(253, 245, 253)
    Note over OP,DB: ขั้นตอนที่ 4: On Machine
    OP->>PY: นำ Tray วางหน้าเครื่อง MBR (On Machine Reader)
    PY->>PY: อ่าน Tag อัตโนมัติทุก 0.5 วินาที
    PY->>API: GET /lot-by-tag เพื่อขอข้อมูล
    API-->>PY: คืนค่า part_no
    
    alt part_no ตรงกับ config เครื่อง (Machine Validate)
        PY->>API: POST /on-machine
        API->>DB: บันทึกสถานะลง tb_rfid_tray เป็น on_machine
    else part_no ไม่ตรง (Mismatch)
        PY->>PY: Alarm ดัง + นำ Tag ใส่ Blacklist
        OP->>PY: (Operator หยิบ Tag ที่ผิดออกไป -> Alarm หยุด)
    end
    end

    %% ========================================
    rect rgb(245, 245, 245)
    Note over OP,DB: ขั้นตอนที่ 5: Completed
    OP->>PY: ยก Tray ออกจากเครื่อง MBR
    PY->>PY: ไม่เจอ Tag นานเกิน COMPLETED_DELAY (600 วิ)
    PY->>API: POST /completed
    API->>DB: อัปเดตสถานะเป็น completed 
    Note right of DB: Tag พร้อมวนกลับมาใช้ใหม่
    end
